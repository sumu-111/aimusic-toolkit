# Demo 素材准备指南

> 目标：现场 demo 用 2 段 **30 秒真实人声**（非合成），一段轻微跑调、一段较重跑调。
> 当前 `assets/` 下已有合成素材用于开发验证，正式 demo 建议替换为真人声。

---

## 一、已有素材（合成，开发/联调用）

| 文件 | 内容 | 用途 |
|------|------|------|
| `assets/test_offpitch.wav` | 16.8s，轻微跑调（±15~45 cents） | 快速联调 |
| `assets/test_offpitch_30s.wav` | 33.6s，轻微跑调 | baseline / 稳定性 |
| `assets/demo_light_30s.wav` | 33.6s，轻微跑调 | demo 备选 A |
| `assets/demo_heavy_30s.wav` | 33.6s，较重跑调（±55~90 cents，听觉明显） | demo 备选 B |

生成方式：`python backend/scripts/make_test_audio.py <路径> <重复次数> light|heavy`

## 二、真实人声录制规格（推荐）

1. **时长**：30 秒内（渲染预算约束，越短越稳），建议 20~25s 即可
2. **内容**：清唱一段简单旋律（单音/级进音阶最佳），**不要伴奏、不要混响**
3. **跑调控制**：
   - 轻微档：多数音偏 20~40 cents（普通人清唱自然就有这个程度）
   - 较重档：故意唱低或唱高半个音内（50~90 cents），但**不要跑超过 2 个半音**（会被守卫拒绝）
4. **录音环境**：手机/麦克风在安静房间录即可；人声靠前，音量别爆
5. **格式**：导出 **WAV 44.1kHz 单声道**（MP3 需先转，避免额外依赖）

## 三、录制后的验收清单（录完跑一遍）

```bash
# 1. 分析：确认 pyin 能检测到音高（pitch 帧多、置信度 >0.5）
python backend/scripts/baseline.py assets/你的素材.wav

# 2. 看输出：修正前 cents 应 >15（说明确实跑调），修正后 <10
# 3. 听产物：backend/output/*_corrected.wav 是否自然、无金属音/爆音
```

- ❌ 修正前 cents < 10：素材不够跑调，换一段或重录
- ❌ 报 PITCH_GUARD：素材有杂音/置信度过低，重录或缩小修正范围
- ❌ 修正后 > 15 cents 或听感怪异：降低 `correction_strength`（0.6~0.8）重试

## 四、现场 Plan B

- 现场无素材/素材损坏 → 用 `backend/output/fallback/` 预生成结果直接展示
- 渲染超时 → `execute_plan` 加 `"prefer_low_sr": true` 走 16kHz 兜底（快约 5 倍）
- 网络异常 → 规则模板离线可用（不依赖 LLM）
